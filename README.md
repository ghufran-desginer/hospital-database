# hospital-database
🗄️ Hospital Management Database (SQL)

مشروع قاعدة بيانات متكاملة لإدارة البيانات الأساسية داخل المستشفى (المرضى، الأطباء، الأقسام، المواعيد، والفواتير)، مصممة وفق أفضل ممارسات تصميم قواعد البيانات العلاقاتية (Relational Database Design).

🚀 الخصائص والمميزات (Database Architecture)

• هيكلة الجداول (Schema Design): جداول منظمة للارتباط بين المرضى، الأطباء، الأقسام الطبية، الفواتير، والتأمين.
• تطبيق المفاتيح والعلاقات (Keys & Relationships): استخدام المفاتيح الأساسية (Primary Keys) والأجنبية (Foreign Keys) لضمان سلامة وتكامل البيانات (Data Integrity).
• الاستعلامات المتقدمة (Advanced SQL Queries):
◦ استعلامات الربط (JOINs) لعرض سجلات المرضى كاملة مع أطبائهم المشرفين.
◦ الدعم بالدوال التجميعية (Aggregate Functions) لحساب الفواتير والتقارير المالية.
• التطبيع (Normalization): تصميم الجداول لتقليل التكرار وفق قواعد Normalization (1NF, 2NF, 3NF).

🛠️ التقنيات المستخدمة (Tech Stack)

• SQL (MySQL / PostgreSQL / SQLite)
• Database Design & ERD Modeling
